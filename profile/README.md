# erlic AI

**Open research on compute-efficient Turkish language models and verifiable reasoning.**

Erlic AI investigates sparse Mixture-of-Experts architectures, Turkish-focused data curation, and verifiable post-training methods for morphologically rich languages.

### Research areas
- Turkish and multilingual language modeling
- Sparse Mixture-of-Experts (MoE)
- Mathematical and logical reasoning
- Code generation and execution-based evaluation
- Efficient training and reproducible benchmarks

### Current status
We maintain an experimental code prototype and are building reproducible validation infrastructure. Large-scale pretraining and benchmark claims will be published only after measured experiments.
